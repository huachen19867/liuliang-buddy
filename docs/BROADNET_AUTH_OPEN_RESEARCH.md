# 广电本机认证开放接入复核（2026-10-05）

本轮承接 `TECH_LOG.md`、`ONE_CLICK_LOGIN_RESEARCH.md` 和 `references/one-click-login-20261005/index.json`。旧官方 App 隐私政策、H5 脚本及官网参考直接复用，没有重新下载。老板的截图已经证明广电官方 App 能以 192 本机号码一键登录；本轮研究的是把同等能力正式授予本应用的渠道，以及认证后能否取得营业厅查询权限。

## 本轮明确的新证据

[腾讯云号码认证 FAQ](https://cloud.tencent.com/document/faq/1415/53464) 的“是否支持广电号码”明确回答不支持，范围限移动、联通、电信。该页亦不支持 Flutter 和 H5。因此腾讯云当前这款产品不能充当本项目广电接入方案。这是该产品的范围，不能推广成广电没有本机认证。

[腾讯云快速入门](https://cloud.tencent.cn/document/product/1415/53463) 还写明当前只有已开通的存量白名单可新购，其他场景不接受新接入。申请通过后由专属技术群提供应用申请与 SDK 材料。这进一步排除了“现在注册腾讯云就能给本应用装广电 SDK”的实施路线。

[阿里云 H5 客户端接入](https://help.aliyun.com/zh/pnvs/developer-reference/h5-client-access) 的 `getLoginToken` 返回字段 `vender` 明确标注暂不支持中国广电，并只列 CM、CU、CT。该文档说明 `spToken` 用于服务端 `GetPhoneWithToken` 取完整手机号，之后由开发者实现自己的登录逻辑。因此该回调不是营业厅会话或流量话费授权。此结论限该 H5 产品和该文档，不能仅据此断定所有阿里云原生产品永久不支持。

[阿里云认证方案管理](https://help.aliyun.com/zh/pnvs/user-guide/number-certification-program-management/) 正文可核实 Android 包名及包签名、iOS BundleID、H5 页面与源地址等应用绑定要求。但本轮搜索摘要含有正文未显示的广电支持范围文字，故不把摘要当成独立证据；广电排除结论使用上一段 H5 正文。

这四份新官方页面已下载至 `references/broadnet-auth-open-20261005/`，`index.json` 保存源 URL、时间、大小和 SHA-256。文件分别为 `tencent-faq.html`、`tencent-quickstart.html`、`aliyun-h5.html`、`aliyun-scheme.html`。仅作参考，没有引入依赖或执行其 SDK。

## 正向线索与可用性边界

中国通信企业协会公开的[《5G 消息业务增强能力规范—统一认证能力要求》征求意见稿](https://www.cace.org.cn/UpLoadFiles/File/20240123/6384159987782049684235492.pdf) 确实包含中国广电运营商编号 4，并描述第三方 Chatbot 申请 GBA 认证、取得应用凭证、经用户授权交换身份信息的设计。因此存在覆盖广电的行业认证设计线索。

但该文件封面仍为征求意见稿、标准编号和发布日期占位；适用场景是 5G 消息 Chatbot 外链，不是普通 Flutter App 内任意网页。它没有给出已运营的广电申请门户、可下载广电 SDK 或营业厅余额授权。本轮只以公开阅读工具核对其封面和相关段落，没有把示例域名当成实际服务请求，更没有把它当成可直接实施的官方产品。资料 URL 保留在本节供后续定向复核。

其他检索命中的“广电客户端号码 SDK”属于互联网电视设备标识，并非 192 手机号码；广电云 Token 平台是大模型调用服务，也不是手机认证。这两类关键词命中不能用于接入。

在广电官网、集团官网域名及开放平台、SDK、统一认证、192 等组合下，本轮尚未定位到可核验的广电面向第三方手机应用的申请页面、原生 SDK 下载与接入契约。这是检索结果边界，不等于不存在商务合作或未公开的能力。

## 可执行的接入判定

现阶段不能落地一个真正能续接营业厅的一键按钮。若后续取得广电合作资料，第一项要验的是接口业务授权：是否明确允许本应用在用户同意后读取该号码流量与话费；返回的是手机号、认证 token、授权 code，还是可用于查询的授权凭证；若只有号码认证，必须再有文档规定的营业厅兑换接口或查询 API。不能因为 SDK 返回成功就把账号标成已连接。

通过这层判定后，才准备本应用自己的 Android 包名和正式签名、iOS BundleID、可用服务端和注册回调地址，取得获批的 appId/密钥、SDK 版本与许可、验签和错误码契约。上述是实施所需信息，不宣称广电已经公布统一企业资质、价格或备案要求；这些目前仍待正式渠道确认。服务端应保存服务端密钥，客户端只持有协议允许的短期结果。

对于公开 H5 或官方 App 跳转方案，必须有广电声明支持第三方宿主的入口与回调契约，再依据回调兑现查询权限。已有 H5 归档的原生 `nativeCall(type:login)` 只是官方宿主桥接；给本项目注入同名对象、改 CBN UA 或复制官网 appId，均不能形成这个契约。正常官网短信登录仍是现有已知可用路径。

## 验证与交接

本轮已用新的网页检索工具读取官方正文，区分搜索摘要和正文差异，下载并校验四份新参考。未使用真实号码、用户凭据、短信、登录授权或认证接口，没有注册/购买服务，没有修改生产代码或运行 SDK，也没有完成广电真机一键登录验证。后续定向外部询证应以“192 第三方号码认证 + 用户授权流量话费查询/营业厅会话兑换”的完整业务范围为题；单独获得取手机号 SDK 仍不足以解决当前问题。

## 继续查找：广电自身合作渠道与供应商（2026-10-06）

老板要求渠道资料由我们主动查找。本轮不再重复三网聚合 SDK 的不支持结论，改查广电自身合作商、代理商、政企招募及实际供应商，新增参考继续放入同一目录并追加索引。

已找到广电自身的[增值业务合作平台](https://open.10099.com.cn/)和[代理商门户](https://partner.10099.com.cn/)。前者公开页面加载的 `js/app.js?v=1784213825205` 已保存；页面脚本指定的匿名首页内容请求 `/gwec-right-portal/api/index/partner_portal/poster` 返回成功，原始响应保存为 `broadnet-open-public-poster.json`。这只是正常公开首页文案读取，没有登录或提交企业申请。

公开首页确实提供企业入驻流程、资质展示以及审核后在工作台申报业务的说明；企业资料涉及营业执照、身份、企业信用资料和银行开户证明等。页面业务分类是权益和彩铃，强调权益运营经验，并有版权/授权和报价等材料要求。其附件模板也对应这些合作流程。当前已核实这是可用的广电合作入口，但没有公开显示“广电账号 SDK”或本机号码认证产品，不能把权益入驻材料当作认证 SDK 的统一申请要求。

[广东广电发布的中广电移动 2026 年全国型权益合作招募公告](https://www.gcable.com.cn/kfhz/hzgg/content/post_108992.html)进一步确认这一渠道的业务范围是权益产品供给。由于并非号码认证接入，未替老板注册、填写资质、发邮件或申请合作。

[亚信官方广电 BSS 建设案例](https://www.asiainfo.com/zh_cn/content_4412.html)确认亚信承担广电业务支撑系统建设，但文章主题是 AntDB 数据库及业务系统，并未声明供应广电账号认证 SDK。已归档作为供应商方向线索，不能据“建设 BSS”推定 App 本机认证由它提供。针对“广电账号”“中国广电账号服务与隐私协议”和 `CbnAuth` 的公开搜索，尚未取得可核验的开发者产品页面。

检索发现[金山世游 SDK 更新日志](https://docs.seayoo.com/sdk/plugin/list/)提到 ksPassport 5.3.2 新增 192 号段，也在不同版本提到创蓝和一键登录。但“号段支持”可仅表示注册/短信输入校验，日志没有明确声称 192 本机免密认证。故它是待证实线索，不能选作现成可用的广电 SDK。

### GBA 状态纠正

进一步找到[中国通信企业协会正式发布公告](https://www.cace.org.cn/News/NContent?key=be41550280bc367eb304f8d4f209c0d9)：该标准已以 **T/CAICI 91-2024** 发布，自 2024-09-15 实施。前文“封面仍为征求意见稿”仅描述当时找到的那一份旧 PDF，不能解释为标准现在仍未发布。正式公告已保存为 `cace-gba-standard-release.html`。全国团体标准平台的正文 PDF 链接本轮返回系统错误，尚未完成最终版全文核对；正式标准发布仍不等于广电已经提供可申请的 192 SDK、GBA 商用入口或营业厅授权接口。

本轮的具体新增结果是找到并验证广电官方合作渠道与公开入驻资料，澄清其权益/彩铃范围，并校正 GBA 标准状态。公开资料尚不足以交付原生认证接线；下一条有效证据应是官方 App 中广电账号协议所指的主体/SDK，以及其公开产品或授权回调文档，而非继续堆砌通用三网 SDK。
