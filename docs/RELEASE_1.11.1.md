# 1.11.1 登录提示改进与已知缺陷

本版按用户明确要求公开发布。功能验收结论仍为未通过：原有331项回归通过，追加10项验收用例中3项通过、7项失败。已知缺陷未在这次发布中修复，完整复现和代码位置见[验收报告](ACCEPTANCE_1.11.1.md)。

新增移动官网本机号码授权框的只读观察和号码提示，以及广电网页登录帮助。取号和授权仍由移动官网执行，用户自行勾选协议并操作；应用不会代为登录。本版没有接通广电原生一键登录，广电仍通过官网短信验证。

已确认修改账号手机号后，提示回调可能继续按旧号码判断，出现错误的“一致”提示或遗漏错号警告。旧登录页或旧WebView的迟到回调可能在新页面弹出错号对话框。离开登录页、开始查询或官网授权框隐藏后，顶部旧提示可能没有清除；同号弹窗再次出现时还可能缺少重复提醒。

掩码比对存在误判：部分格式的中间公开数字或隐藏位长度没有严格校验，国家区号也可能导致错误提示。即使标准掩码可见数字相同，也不能证明完整手机号一致，因此不要把应用的“一致”提示视为号码身份已验证。多卡或修改号码的场景建议优先使用官网短信登录；修改号码后可彻底退出并重新打开应用，仍须人工确认当前数据卡和目标号码。

广电帮助中的“未向第三方应用开放”表述缺少官方证明。准确状态是本应用尚未取得可用的广电原生SDK及查询授权兑换资料，不能据此判断运营商是否向其他合作方开放。帮助文案也不能替代正式接入。
