# 电信套餐名称分类与首页展示

老板确认的分类口径：电信套餐名称包含“定向”时归入定向流量；名称不包含“定向”时归入其他流量，包括“国内上网流量”“国内上网流量含 X GB”等无法进一步确认用途的名称。其他运营商仍按原来的分类名称展示。

首页将电信的 unknown 分类显示为“其他流量”，不显示“用途未知”或“用途待确认”。定向与其他流量在类别摘要中分别展示，电信估算值继续带“约”。套餐详情的分类弹窗将当前 unknown 说明为“其他流量”。

电信同名套餐在列表中合并为一行并汇总所有可确认子项的估算余量；任何子项缺少可确认余量或单位时，整组显示“待确认”，不展示部分和。全组明确标注不限量时显示不限量；有限项和不限量混合时不把有限余量加到不限量中。点击合并行仍可逐项核对官网明细，弹窗说明合并估算及子项数量，并注明同名余量相加不代表官网套餐彼此独立。其他运营商同名组继续使用原来的“共 N 项”展示。

电信 partial 状态下，如果通用、定向、其他三组都无法显示余额，首页提示“部分套餐余量待确认，详见明细”，不要求用户再设置用途分类。类别中已有可确认数据时，继续分别显示可用的估算组和待确认组。

UI 回归位于 `app/test/ui/dashboard_screen_test.dart`；组合预览由测试生成到 `artifacts/telecom-directed-other-partial-preview.png`。此预览使用合成数据，不代表运营商真实账户结果。

根集成调整合并后的查看数量：电信显示合并后的组数，不再显示原始子项总数；例如24子项归4项，入口为查看全部4项。完整合并明细保留数值和来源说明，原始条目可逐项核对。组合预览恢复页顶并显示演示数据标记。最终完整Flutter278项/28秒通过、analyze无问题，新增FlowHome旧缓存启动到Widget通道回归通过；不代表真号/手机桌面实际验收。
