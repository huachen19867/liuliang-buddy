# 通话与短信首页展示（2026-10-01）

先读取 TECH_LOG.md，复用现有 Dashboard 卡片、数据来源脚注、窄屏布局和实际组件截图工具，不新增第三方 UI 框架。官网字段证据与模型由协议/解析任务负责，本文件记录首页展示。

每个号码的流量主位下面增加薄荷色通话面板与淡紫色短信面板。每项保留官网名称和用途，不将多个套餐简单相加；联通“短、彩信”显示合并范围，不假称纯短信。剩余量未知显示待确认，真实零显示零；超额单独显示“超出”，不限量保留文字。电信按已用/总量计算的条目标“约剩余”，短信保留官网“次”或“条”的原单位，只有单位一致才估算，不虚构换算关系。

未连接时显示等待连接。登录过期或刷新失败，继续显示原缓存，并由同卡来源脚注明原查询时间；即使只有通话短信而没有流量缓存，也保留该说明。面板在小于 300px 可用宽度或放大字号时竖排，正常宽度并排，长套餐名称和用途可换行。

新增测试覆盖未知/零/超额、用途不合并、过期查询时间、四卡 320px 和 1.4 倍字号、仅服务余量缓存、估算/不限量/未换算来源单位。实际组件 DEMO 截图预定输出 `artifacts/dashboard-voice-sms-demo.png`；样本不是用户实际余额。测试与截图执行需协调共享 Flutter SDK 串行，验收结果追加在此。

本次范围是应用首页。Android 桌面卡片及 iOS WidgetKit 仍展示流量，不在这里暗改快照协议或原生布局；如用户需要桌面也展示通话短信，应另做布局与协议适配。


根集成后串行执行首页测试21项全部通过，dashboard-voice-sms-demo.png已生成并目视核对，真零/未知/超额布局清晰无溢出。电信明确短信资源按原单位‘次’估算，UI使用每项实际单位。
