## 本轮具体进展

找到此前未归档的广电[公开 SSO 登录页](https://m.10099.com.cn/ssoserver/login.html)，以及官网[自动回跳页](https://m.10099.com.cn/h5wap/busiClient/login/autoLogin.html)。它们提供了真实的官网 SSO 票据到网站会话交换证据；但前者的 HTML 明确要求手机号、短信验证码与图形码，未提供本机 SIM 免短信按钮。不能把 autoLogin 的名称当成号码认证。

正常引用的 `ssoserver/js/login.js` 在 `login()` 中构造 `username`、`accessCode`、`service`、`captcha`、`captchaKey`。成功时重定向到响应 `data`。这是静态源码事实；没有填写号码、发送短信或提交登录。

官网正常引用的 `autoLogin-212688efdc.js` 则读取 URL 的 `ticket`，经 Request 请求相对路径 `/api/user/login?ticket=...`。其 base 配置为 `/gwec-h5control-wap`；成功业务码是 `000000`，响应 `result.sid` 经网站存储封装写入 `COMMON_H5WAP_TOKEN`，随后使用 `sso_redirect` 指定的目标进行服务端 `ssoRedirectUrl` 检查，检查路径为 `/api/ssoConfigCheck/ssoRedirectCheck`。只有通过后才导航。网页源码可作为后续识别证据，不能视为已经为本应用提供的开发者 API。

请求封装还区分 `H5WAP_TOKEN`、`COMMON_H5WAP_TOKEN` 与销售端令牌。这里的 sid 存储不等于现有流量查询 WebView 采用的 `phoneInfo/sessionId`；本轮没有取得两套会话的转换约定，也没有测试用一个替代另一个。没有运行归档 JS、复制其中的签名常量到生产代码或请求认证/票据兑换端点。

## 公开协议能证明什么

按照登录页已有的协议阅读路径，匿名读取 `/ssoserver/api/getAgree` 与 `/ssoserver/api/getConceal`，均返回 `respCode=0000`。请求为页面规定的 POST，但用途仅获取公共协议，不含用户身份、cookie 或表单数据，不涉及登录/短信/业务变更。

服务协议的正式标题是《中国广电第三方电子渠道服务协议》，主体为中广电移动网络有限公司。这里“第三方电子渠道”具体包括它自己在微信、支付宝等平台的官方服务；正文包含业务查询，并要求相应服务权限。该标题不是向任意第三方 App 授予 SDK、营业厅数据或回调接入的合同，不能据它自行补造应用授权。

隐私响应标题是《中国广电自有电子渠道隐私政策》，所返版本日期仍为 2022-06-27，早于已有官网 2025-06-16 归档。它列举支付、网页内核和人脸/OCR SDK，没有列出截图中的《中国广电账号服务与隐私协议》及原生认证 SDK。旧协议不足以否定官方 App 原生能力，也不宜视为最新完整 SDK 清单。

## 定向检索的实际边界

本轮对“中国广电账号服务与隐私协议”“中国广电账号”+SDK、`CbnAuthDialog`、`cbn_account`、广电免密认证、广电号码认证平台、中广电移动一键登录、广电认证招采和亚信官方产品分别检索。还限制官方 10099/广电集团、亚信和认证供应商域名进行交叉核对。没有获得可核验的广电 192 原生第三方 SDK 名称、Maven/AAR 坐标、签发应用凭证入口或 SIM token 换 SSO ticket 文档。这是本次公开检索的结果，不能推论“广电没有 SDK”。

搜索中的广电电视/机顶盒客户端编号、宽带 AAA、号码标记和三要素产品都不是 SIM 本机认证。既有金山世游 192 更新仅说明号段支持，仍不能证明免短信。极光当前资料仍描述三网认证；未将三网聚合 SDK 作为广电实现，也未为了增加资料数量下载这些无关项目。

## 能落地到哪一步

可确认并复用的是官方 SSO 网页及其自身短信登录后的票据交换链路。它没有补上“本应用 Android 原生 SDK 调用 → 广电 SIM 认证结果 → 获准查询营业厅”的入口，因此本轮不具备真实原生一键接线条件。

仍需确切取得支持广电数据 SIM 的获授权原生库及版本/分发许可、适用于 `cn.liuliang.liuliang_app` 正式包签名的独立应用配置、SDK 方法和成功/取消/失败回调格式。若其结果只有手机号或认证 token，还需要广电明确支持该结果兑换营业厅票据或只读查询授权的接口、应用注册与回调规则、验签方式、有效期和续期规则。不能把公开 SSO 页的 `service` 参数当成任意第三方回调已获准的证据。

本轮只验证匿名公共资料响应成功、归档文件和源码关联，未注册、购买、联系外部、执行 SDK、使用私有应用凭据或做真机 192 认证。未改生产代码，未产生可宣称接通的新安装包。根代理可将上述新 SSO 证据并入本轮技术日志；参考索引记录每个原始文件和派生文本的来源与哈希。
