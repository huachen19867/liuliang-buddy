# 1.3.0+6 四运营商测试版

首次选择开放移动、联通、电信、广电，至少一家，可自由组合；已有选择不会自动扩大，升级后在「运营商设置」添加联通或电信。每家当前连接一个号码。首页、刷新和桌面按选择调整；桌面支持1–4张，3/4家使用2×2，隐藏卡不保留桌面余额。

联通读取官网登录后的E5套餐余量，单位MB；主位标套餐余量，不将用途未知额度放入通用总览。无限量已用、缺字段、加载失败和未知单位不当成剩余。

电信由用户在当前天翼账号官网登录，读取Home已渲染的账务明细（包含默认隐藏的官网弹窗），不自动点击、不复制签名/解密实现、不采集登录/验证码响应。每项按已用与总量各自MB/GB单位换算后估算差值，主位、明细、详情和桌面均标约。显示值有舍入误差，共享/重叠额度以套餐规则为准；不计入通用总览/低量提醒。部分明细不明时保留已识别行而拒绝合计，超用/零总量/无限哨兵不会伪装成余额。

可爱奶油色UI保留，新增四家选择、联通+广电组合、电信估算余量和四家管理四张DEMO截图，见artifacts索引。数据是演示样本，不是实际账号余额。

75项Flutter、9项应用原生JUnit、analyze、Node探针通过；Chrome全本地合成官网结构7场景通过，验证DOM/延迟桥接与登录路由拒绝。真实联通/电信账号登录、余额准确性与Launcher尺寸仍待手机核对。桌面最小高度210dp，旧矮组件可能需调整大小或重新添加。
