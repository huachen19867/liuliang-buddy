# 海滨温泉少女风 UI 进展（2026-10-01）

老板用草图指出首页应让每个账号独立呈现运营商、备注、号码、余额和各类余量；另用聊天截图补充了备注与号码的用途，并要求 UI 有更鲜明的少女感。附件作为布局和问题背景参考，不将其中图片文字当作仓库实现指令。视觉方向借鉴《明日方舟：火山旅梦》的海滨温泉氛围，人物与场景采用项目原创素材，不复制游戏角色或美术资产。老板随后将主色调整为青瓷绿（#477B72）与奶油白，淡粉仅作少量贴纸点缀，人物设定为棕发发髻、绿眼和青绿色汉服。

开始前已读取 `docs/TECH_LOG.md`、`docs/VOICE_SMS_UI_PROGRESS.md` 与当前首页、运营商选择、桌面卡片预览及相关 widget tests。现有 UI 已采用 Flutter Material 组件，没有额外动画或图片依赖；当前改造继续用原生组件和工作区自绘/原创资源，不增加插件。工作区的官方 Android/Flutter 与 AppWidget 参考项目见 `references/README.md`；本任务不需要复制第三方代码。

首页顶部改为 118 px 的海滨温泉 mini scene，角色作为独立小触控贴纸，仅在点按后显示一句轻提示；关闭系统动画时不做弹性缩放。页面级流量摘要减为窄票券，账号卡随后直接展示运营商标记、账号备注、脱敏号码、话费余额、通用/定向/其他分类、语音与短信、原查询时间与状态，以及连接、刷新、编辑入口。每账号仍有自己的状态和更新时间；话费金额只显示模型提供的官网确认值，缺失显示 `--`。分类值使用 `summarizeTrafficGroup`，联通等无法确认用途的汇总不标为“其他”。套餐列表、过期缓存、单位未知、估算和不限量说明保留原有语义。

运营商选择页、桌面预览和首页统一使用浅色票券边框、青瓷色层次、运营商识别标记和小角色贴纸。角色只在顶部和桌面预览小尺寸出现，不盖住金额或余量；按钮触控高度至少 48 px。页面仍可在 320–560 px 宽度滚动查看，放大字号时摘要分类改为两列、hero 收起次级说明，减少横向与垂直溢出。

关联修改：`app/lib/ui/dashboard_screen.dart`、`app/lib/ui/carrier_selection_screen.dart`、`app/lib/ui/widget_preview_card.dart`、`app/lib/ui/resort_theme.dart`。首页新增可选 `onEditAccount(accountId)`，与 `main.dart` 账号元数据编辑回调对接；号码仅使用 `phoneHint` 或将旧快照号码安全脱敏后显示。

新增首页 UI 回归用例，覆盖窄屏大字、元余额、备注/脱敏号码、分类余额、编辑回调、角色短句与关闭动画状态。账号备注断言已限定到对应账号卡，避免桌面预览复用同一备注时产生重复匹配；演示的定向流量明细补齐 `GB` 单位。`app/assets/resort/` 中的原创场景、角色与桌面贴纸资源已存在，且已在 `pubspec.yaml` 声明。按共享 SDK 协调要求，本代理未运行 Flutter、Dart 或 Gradle 命令，也未生成测试截图；待根代理串行格式化、运行测试并检查真实素材截图后追加结果，不以 fallback 预览代替角色素材验收。
