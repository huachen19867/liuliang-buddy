# 安卓三卡与四卡桌面话费显示

本次只调整 Android Launcher 小组件的三卡/四卡紧凑行。Dart 传入的账号级 `balanceYuan` 已由原生缓存接收；金额仍须来自上层已确认的查询结果。本次不新增中国移动话费接口，不更改数据协议，也不改 iOS Widget。

紧凑行继续用原摘要显示流量和状态，并使用原先隐藏的话费 TextView 单独显示金额。金额行使用 `¥xx.xx`，后接该快照的查询时间；金额无效或查询时间缺失时整行隐藏。为免增加行数，有有效话费时隐藏单独的时间行；金额放在文字开头，窄宽度下时间可被省略。没有有效话费时，原查询时间行仍照常显示。这样话费不会占用流量/状态摘要的宽度，50dp 卡片也维持原高度。

新增的原生单测覆盖三卡、四卡紧凑模式下流量摘要与话费值分行，查询失败时保留状态与缓存金额，以及无金额、缺查询时间和未连接时隐藏金额。按照本任务要求未运行 Android SDK；测试结果待集成阶段执行。
