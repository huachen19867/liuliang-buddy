# 移动一键授权框观察与广电登录帮助（2026-10-11）

验收补充：下文保留实现阶段的设计说明，不能当作全部行为已通过验证。后续真实FlowHome验收发现账号编辑、迟到回调、提示清理及掩码判断缺陷，10项新增用例有7项失败；广电“未向第三方开放”的表述也缺少官方证据。用户要求带已知缺陷发布，实际范围见[1.11.1说明](RELEASE_1.11.1.md)和[验收报告](ACCEPTANCE_1.11.1.md)。

老板要求优化移动广电的本机一键登录。本轮不做任何新的原生 SDK 接入：广电原生一键此前多轮已核实缺少面向第三方的正式 SDK、应用授权与营业厅兑换契约（见 `BROADNET_NATIVE_LOGIN_*_20261007.md` 三份报告与 `ONE_CLICK_LOGIN_RESEARCH.md`），本轮在其边界内把「移动官网自带的一键登录」用得更可靠、更安全，并把广电的登录边界如实告知用户。

## 移动：官网授权框弹出时的号码核对

移动官网 `wx.10086.cn/website/bind/bindAccount/new` 在页面就绪时自行取号，成功后弹出 `.onekeyLoginPop` 授权框，框内 `#onekeyLoginPhone` 显示掩码号码。此前应用只有静态指引文字，用户（尤其多账号用户）不知道授权框已出现、也无法对照当前账号核对号码；`ONE_CLICK_LOGIN_RESEARCH.md` 明确要求「必须由用户核对官网掩码号码是否匹配当前目标账号」。

新增 `page_probe.dart` 的 `mobileOneKeyProbeScript`，仅在移动登录页 document-start 注入：

- 每 300ms 读取 `.onekeyLoginPop` 的计算样式与 `#onekeyLoginPhone` 文本，弹出且含数字时经新桥 `oneKeyPrompt` 上报一次 `maskedPhone`；掩码变化重新上报，弹窗隐藏后重置，同一弹窗不重复发送。
- 只读观察：不点击、不勾选协议、不提交、不读取短信表单；离开登录路由即停止轮询。非登录页、子框架、非官方源不注入。
- 它不是查询响应：不携带 `queryEpoch`，不进 `_receive` 的响应门禁，走独立 handler。

`main.dart` 新增 `_receiveOneKeyPrompt`：仅在当前屏幕显示该账号的官方页时接受事件，按账号登记的 `phoneNumber` 与官网掩码做前缀/后缀数字比对（`carrier_web.dart` 的 `compareMobileOneKeyMask`），只比较公开数字、不猜隐藏位；掩码无隐藏位时要求整号相等，无法解析时报 unknown。

结果分三档显示在官方页顶部提示区（新 `_loginHints` 缓存，按账号清理）：

- 一致：提示框内号码与账号一致，请自行勾选协议后点「一键登录」，并说明「3天免登录」由官网控制。
- 不一致（多卡最容易踩的错）：明确提示点官网「暂不使用」改用短信验证，或先更正账号号码，并弹一次对话框强调；同一弹窗不重复弹。
- 无登记号码：中性提示框内掩码号码，请用户自行核对后再同意。

提示在重新连接、重新加载登录页、SPA 回到登录页、查询提交和清除资料/改选/移除账号时清空，不会把旧弹窗提示带到新一轮登录。掩码比对与文案为纯函数，测试在 `carrier_web_test.dart`；脚本行为（可见性、去重、重报、页面/框架守卫、桥接延迟到达、轮询有界）在新增 `mobile_one_key_probe_js_test.cjs` 覆盖。

## 广电：如实说明一键不可接入与短信登录路径

广电官网登录页没有一键入口，原生一键缺正式接入资料，本轮不造假按钮。改进点：

- 新增 `broadnetLoginGuide` 默认提示与 `broadnetLoginHelpMessage` 帮助弹窗（此前广电无帮助入口）：说明官网用短信验证码；官方 App「本机登录」由其自有认证服务提供、未向第三方应用开放，本 App 不提供也不冒充免验证码登录；本机会话备份会在重开页面时尝试恢复、官网拒收时清除，备份不延长官网有效期（有用户反馈约三天）。
- 移动帮助新增一句：授权框弹出时本 App 顶部会同步显示框内掩码号码，本 App 不会替用户勾选协议或提交；并引用官网弹窗自带的「请勿连接热点登录」提示。

## 边界与验证

本轮没有接通任何新的本机取号链路：授权框仍由移动官网弹出、由用户自行同意；广电仍走官网短信验证。所有新代码只观察官网自己的 UI 与文本，不注入点击、不复制认证实现、不改动官方请求。Flutter 331 项测试与 `flutter analyze` 通过，全部既有 Node 探针回归通过。官方页真实设备上的取号兼容性（Wi-Fi、双卡数据卡归属、各省差异）仍需真机自愿验证；广电原生一键的正式接入仍以官方或其授权供应方的回应为准。
