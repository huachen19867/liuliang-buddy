# 流量小伙伴测试版数据说明

本应用的用途是在一个安卓界面查看移动、联通、电信、广电的官方流量查询结果。号码验证由用户直接在各运营商官方网页完成，不读取短信、不代发验证码、不采集服务密码。

联网目标为运营商官网及官网自己的资源。应用没有第三方业务服务器，不把号码、余额和凭证发送到开发者服务器。运营商网页的隐私与登录条款由网页本身提供。

官网 Cookie 和浏览器存储由 Android WebView 在本应用沙盒中管理。每家最多两个账号，第二个使用独立 Android WebView Profile；设备不支持时不能添加第二个同运营商账号。第一个沿用原来的默认会话，不复制其凭证给第二个账号。广电必要会话字段通过 flutter_secure_storage 按账号分别备份，用于重启后尝试恢复。备份最多保留七天，官网可以提前使会话失效，应用不会延长官网授权。登录页面不恢复旧广电会话，官网拒绝后清除对应备份。

余额查询记录、脱敏号码（若响应提供）、更新时间和提醒设置保存在本应用的本地偏好存储。安卓版关闭系统备份。应用只读取移动、广电及联通已确认查询接口的响应，不抓取登录和验证码响应，不保存原始完整响应作为调试日志。

提醒设置中的“清除号码连接与本地数据”会取消后台周期任务，移除本应用中各家官网 Cookie、默认与独立 Profile 网页存储、广电会话备份和余额记录。清理失败时明确提示并暂停查询，直至重试完整清理成功；不会把部分清理当作全部完成。它不会更改运营商账号，也不会删除其他 APP 的数据。收起第二张卡或隐藏一家运营商仅停止展示与查询，保留其本地记录和会话。

前台自动查询发生在 APP 打开、返回前台和每五分钟。桌面卡片后台刷新默认关闭，可选择每小时、每两小时或每天尽力刷新。后台最近尝试时间与结果另存在本机，不包含官网登录资料或原始响应。低流量通知需要用户在设置中启用及安卓允许通知，并仅基于成功查询的有限通用流量额度触发。官网标记的不限量套餐不换算成数值、不触发低量通知；达量限速等以官方规则为准。手机号属于哪一个实体卡槽并未自动读取，卡片按运营商和账号序号标记。

桌面卡片后台刷新默认关闭，可选每小时、每两小时或每天。启用后由本机 Android WorkManager 在有网络时尽力执行，任务使用本应用的无界面 WebView 与已有本地官网会话，不经过开发者服务器；只有已选中且曾成功查询的移动、广电、联通会尝试后台查询。电信账务读取依赖前台已渲染页面，后台任务会跳过。省电限制可能延迟任务，完整范围和验证边界见 `docs/WIDGET_BACKGROUND_REFRESH.md`。

桌面小组件仅另存展示所需的所选账号标识、运营商、账号序号标签、余量或不限量标记、用途标签、查询时间、状态和提醒阈值，存于本应用的私有 SharedPreferences，不含手机号、Cookie、验证码或会话凭证。清除本地连接时同时清除小组件缓存，桌面回到未连接。点击卡片打开本 APP；组件不运行自动登录，启用的后台查询由上述 WorkManager 任务执行。

已收到用户真机双卡同步截图；准确性、完整登录流程、更多设备和套餐、通知行为仍需实际对照验证。运营商账单本身可能延迟，页面和桌面卡片展示查询时间；断网或认证失败时旧查询记录明确标记，不能作为最新余额使用。广电“套餐明细合计”是明细余额的数学汇总，适用范围以各套餐规则为准，不视为已确认的通用额度。

首次使用由您选择需要显示和查询的运营商，至少一家。运营商选择与完成标记保存在手机本地，不读取SIM卡槽。隐藏一家会停止其查询、卸载网页并取消旧通知，从首页与桌面卡片移除；已有本地记录和会话仍保留，重新选中时可尝试恢复。要删除这些数据，请使用清除号码连接与本地数据，清除后保留运营商选择。

1.3.0新增联通官网套餐余量读取，Cookie仍由官方WebView本地管理。电信使用官方e.dlife.cn天翼账号页面，由用户完成验证；只读取指定账务组件已渲染的流量条目，隐藏的明细弹窗也可能包含这些数据。不会读取或导出加解密密钥、天翼账号登录响应、服务密码或验证码。电信数值由官网已用/总量显示值估算，有舍入误差，明确标约且不触发通用提醒。网页不能确认有效单位/额度时仍显示待确认或错误，不虚构零余额。
