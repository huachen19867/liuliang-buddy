# 流量小伙伴测试版数据说明

本应用的用途是在一个安卓界面查看中国移动、中国广电的官方流量查询结果。号码验证由用户直接在各运营商官方网页完成，不读取短信、不代发验证码、不采集服务密码。

联网目标为运营商官网及官网自己的资源。应用没有第三方业务服务器，不把号码、余额和凭证发送到开发者服务器。运营商网页的隐私与登录条款由网页本身提供。

移动网页的 Cookie 和浏览器存储由 Android WebView 在本应用沙盒中管理；广电会话字段在同一个官方 WebView 中使用，并将必要字段通过 flutter_secure_storage 存入安卓安全存储，用于重启后尝试恢复。备份最多保留七天，官网可以提前使会话失效，应用不会延长官网授权。登录页面不恢复旧广电会话，官网拒绝后清除备份。

余额查询记录、脱敏号码（若响应提供）、更新时间和提醒设置保存在本应用的本地偏好存储。安卓版关闭系统备份。应用只读取两家已确认查询接口的响应，不抓取登录和验证码响应，不保存原始完整响应作为调试日志。

提醒设置中的“清除号码连接与本地数据”会移除本应用中两家官网 Cookie、网页存储、广电会话备份和余额记录。它不会更改运营商账号，也不会删除其他 APP 的数据。

自动查询仅在 APP 打开、返回前台和前台每五分钟运行；APP 关闭后不持续监测。低流量通知需要用户在设置中启用及安卓允许通知，并仅基于成功查询的通用流量额度触发。手机号属于哪一个实体卡槽并未自动读取，卡片仅按运营商标记。

桌面小组件仅另存展示所需的两卡余量、用途标签、查询时间、状态和提醒阈值，存于本应用的私有 SharedPreferences，不含手机号、Cookie、验证码或会话凭证。清除本地连接时同时清除小组件缓存，桌面回到未连接。点击卡片打开本 APP，不在后台独立运行登录或查询。

测试版还未用真实号码验证登录、查询准确性、网页兼容性与通知行为。运营商账单本身可能延迟，页面和桌面卡片展示查询时间；断网或认证失败时旧查询记录明确标记，不能作为最新余额使用。
