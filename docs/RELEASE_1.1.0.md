# 流量小伙伴 1.1.0 测试版

新增 Android 双卡桌面卡片，分别展示中国移动与中国广电的上次查询余量、时间和状态。APP 中点击“添加桌面卡片”可申请系统固定；不支持的桌面可长按空白处手工添加小组件。点击卡片打开 APP 更新，清除账号数据时同步清空桌面展示。

保留奶油底色、蓝色移动与蜜桃广电的可爱界面。通用与定向流量分开，失败保留原查询时间，未连接不显示示例余额。卡片只保存展示数据，不保存手机号、验证码或运营商凭证。

安装包为 liuliang-buddy-debug.apk，版本 1.1.0/code 2，Android 7.0/API 24 起，ARM64 手机，大小 89,496,179 字节。个人测试用 Android Debug 签名，未启用 DEMO。首次分别在两个运营商官方网页完成验证。

SHA-256：`72a57ebaa68dec4811e212416665cf7c810fb2a37dbe56976759708bb10bd520`。

完整 Flutter 24 项测试、原生卡片 5 项测试、Node 网页探针验证与静态分析通过；APK v2 签名、名称、版本、SDK、权限与 provider 注册已核对。Web DEMO 使用独立演示数据，不能证明真实余额准确。

尚未连接真机或真实号码，运营商登录、各地套餐、会话续用和桌面添加/缩放/点击仍需实际手机验证。卡片显示最近结果，APP 关闭后不持续查询，不保证亮屏自动刷新；官网变化或会话过期时需重新验证。私有 GitHub 仓库和 Release 需要有访问权的账号登录。
