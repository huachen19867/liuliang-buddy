# 套餐用途手动分类

首页套餐明细保留自动识别的前三项折叠方式。点开任一套餐可查看完整余量与总量，并在支持的条目里选择“自动识别”“通用流量”或“定向流量”。自动识别会清除本地修正，恢复运营商原始分类。

保存由主应用回调处理；成功后关闭弹窗，失败时留在当前选择并允许重试。分类只影响本应用的统计和卡片，不会改写运营商返回的套餐数据。普通演示入口没有保存回调，继续显示只读详情。

运营商汇总项以及重名、空名套餐无法可靠地映射回单条明细时不开放分类，会显示简短原因。当前 snapshot 未包含该套餐时同样阻止保存。手动分类标记只在已有本地覆盖时显示；自动项不额外增加标记。

弹窗沿用青瓷绿与奶油白主题，选项使用整行触控区域。详情与选项可在弹窗中滚动，小屏和系统大字仍保留取消与保存操作。

定向 UI 覆盖见 `app/test/ui/traffic_classification_dialog_test.dart`。实际 Flutter 组件合成预览为 `artifacts/traffic-classification-preview.png`；预览数据为虚构套餐，不代表运营商账户。
