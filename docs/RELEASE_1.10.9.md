# 1.10.9 登录资料恢复与过期误报

广电会话备份不再因本地保存超过七天而被自行弃用，仍由官网响应确认是否有效。重启、前后台查询使用同一校验；网页只有游客字段时整对恢复备份，官网已有完整新登录时保留新登录。

广电查询成功后及时保存当前完整资料，避免仅比较会话编号而漏掉手机号信息变化；恢复脚本随新资料更新。后台在成功响应后捕获资料，并在保存前复核账号、旧凭证和任务状态，减少旧请求覆盖新登录的问题。网页资料读取限时，失败不会卡住查询。

移动、广电没有明确认证失效证据的 HTTP 403 视为查询错误，避免误报登录过期并暂停周期查询。HTTP 401、广电业务701及明确的认证过期文字仍要求重新验证。移动帮助说明官网“3天免登录”的期限及其与查询刷新的区别。

老板已确认广电三天后官网也要求重新收验证码，这是官网真实失效；本版没有可验证的服务器续期接口，不能承诺消除这个三日重新登录。保留上次数据与时间，真正失效后仍需官网短信验证。没有真实账号的连续三日验证。
