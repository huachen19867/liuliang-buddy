# 1.10.7 移动话费与桌面同步

移动原流程只解析流量，没有取得话费余额。本版读取中国移动官网首页明确标记“话费余额”或“账户余额”、且明确使用元单位的可见数值，同一账号本轮流量与话费合并后保存并发布桌面卡片。零余额和负余额均保留；不会拿实时费用、欠费字段或旧缓存冒充本次余额。

流量成功后话费独立限时等待五秒，缺失时保留成功的流量并提示“话费余额暂未取得”。支持金额先到和流量先到；取消、换号码、登录跳转和重新查询不会将上一轮金额写进新账号。Android 三、四卡紧凑卡片同步保留有效话费信息。

同时包含此前本机 1.10.6 的电信名称分类与同名合并。1.10.6 没有单独公开发布；产品规则及估算边界见 [1.10.6 说明](RELEASE_1.10.6.md)。
