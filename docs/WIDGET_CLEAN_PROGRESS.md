# 桌面卡片信息精简进展

2026-10-01。先读取 `docs/TECH_LOG.md`、现有 `WidgetAccountDetails`、`WidgetPresentation` 和原生测试，复用工作区已下载的 Google AppWidget 官方示例与既有白名单缓存，不另建组件架构。此次精简聚焦每账号桌面卡片：正常查询不重复显示状态文案；原始查询时间仍保留，超过二十四小时的记录明确显示“记录较早”，与既有缓存展示时效一致，避免短于每日后台周期。查询失败、登录已过期、查询中、未连接和缺少有效时间仍给出相应状态，不能因隐藏装饰信息丢失操作线索。

话费仅在有有效原始查询时间且金额合法时出现，没有金额则隐藏整行。合法的零元和负余额保留，不用零补缺值。流量分类及通话缺少有效数据时显示短横线“—”，明确的零余量和不限量仍保留。三类流量已有有效 `provided` 数值或 `unlimited` 状态时隐藏重复主摘要；三类均无确认数据时保留原始主摘要，包括联通旧缓存的套餐余量、套餐明细合计、估算标识和不限量，不把合计误放进某一分类。主摘要自身缺值、缺原始时间或时间异常时隐藏，不生成占位摘要。

`WidgetAccountDetailsTest.kt` 已调整缺失话费及分类占位断言，新增缺值与真实零值、负余额、成功状态省略、二十四小时边界、失败/认证失效/加载状态、分类抑制重复摘要、缺少主数据、未来时间、旧联通聚合缓存、缓存失败保留余量、不限量和估算标识回归。已有 `WidgetPresentationTest.kt` 保持原规则，通知栏与快捷设置等使用方的旧展示语义不会由此测试改写。
