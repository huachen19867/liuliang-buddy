# 部分套餐的小组件展示契约

2026-10-02。先读 TECH_LOG，复用已有 home_widget 官方参考、RemoteViews/WidgetKit 桥接和原生 XML 预览，不引入插件或复制第三方业务源码。

新增 trafficReadableCount、trafficPendingCount、previewRemainingBytes、previewUnlimited 四个展示字段。仅电信有原查询时间且非未连接时计数；套餐必须有完整名称与明确单位、合法非负余量，或明确不限量且没有冲突字节数。主汇总未知、至少一项可读且至少一项待确认时，预览取第一条可读明细，绝不局部相加。原主金额、用途分类和低量提醒规则保持保守。

Android schema1 和 schema2 均校验并持久化四字段，旧缓存无字段默认不预览。状态、时间及原值保留。新预览限定电信、有效时间、无主金额、计数各1–200且合计不超过200、有限值与不限量互斥。标明单项与估算，通知和快捷设置也保留单项标签。所有类别及通话均不可用时，小组件隐藏空格子，用单项余量和缺项提示替代；有有效分类或通话时继续显示原格子并在旁边补单项摘要。

同名套餐折叠是 APP 列表交互。桌面不展开长列表，点击组件按既有入口打开 APP 并尝试刷新，查看完整分组与逐项余量。没有字段意味着待确认，而不是零。认证失效和查询失败保留原查询时间及错误提示，不冒充新同步。

预览为脚本读取实际 XML、形状与位图的合成图，不是手机实拍。Android 实际绑定和数据格式需原生单测及签名构建；iOS 源码及编译边界另见 WIDGET_PARTIAL_IOS.md。
