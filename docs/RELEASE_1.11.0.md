# 1.11.0 查询稳定性与连接检查

修复移动已返回流量后页面验证失败仍一直查询的问题。页面读取、加载和余额等待都有终止期限，失败保留原有效数字和时间，可以重新尝试。网页响应按发起时的账号查询轮次识别，旧页面回包、迟到 getUrl 或 loadUrl 不能覆盖新查询。没有轮次身份的原生网页错误不会结束较新的请求，由本轮期限收尾。

广电进入登录页后先结束查询，再清理旧备份，脚本/本地删除失败也能重新连接。Android 沿用 Flutter Secure Storage 11.2.0 和原加密实现，新增跨引擎共享的真实完成回调队列；Dart 超时不代表底层写入已取消。清理未完成会保留门禁，不能把迟到写入和部分删除宣称成功。联通本地凭证读写错误不视为官网认证过期，不因此永久停止后台查询。

设置增加“连接与刷新检查”，区分登录过期、访问错误、部分字段未读、正在查询和未连接；展示实际安装版本、自动刷新间隔、后台结果，以及最近有效数据/最近尝试时间。按钮接入真实重新登录、重试、字段核对和设置路线。诊断报告不含完整手机号、私人备注、token 或原始服务端响应。

移动与广电有限流量响应中余量大于总量的矛盾数字与缓存统一判定为待确认，原始行保留；真零、缺失总量和官方不限量标记仍遵循原规则。不凭套餐名称容量生成可用余量。
