# 1.9.1 桌面卡片精简与玻璃质感

[下载唯一正式 APK](https://github.com/huachen19867/liuliang-buddy/releases/download/v1.9.1/liuliang-buddy-release.apk)，Android 7+ ARM64，可覆盖正式签名的1.8/1.8.1/1.9.0。

桌面卡片删除未填号码、未提供话费和无查询时间的占位行，正常状态不再显示“上次记录”，底部重复刷新说明收起。已有分类数据时不再重复左侧流量摘要；联通或旧缓存仅有套餐总余量时保留唯一数据。真正的0元/0分钟与不限量继续显示，缺失分类用短横线，查询失败、登录失效、加载和较早记录仍可辨认。

小框调整为半透明白底、轻细边框和深灰文字，降低原来绿底绿字的沉闷感，角色保持靠边小尺寸。普通 Android RemoteViews 小组件不能自行模糊壁纸，此版提供半透明玻璃质感，不宣称真实背景毛玻璃。应用内主题与iOS原生组件本次未调整。

沿用1.8.1启动修复与正式签名。原生JUnit26项通过，覆盖缺值隐藏、零值保留、联通唯一摘要和24小时状态边界；共用Flutter代码没有修改，既有144项测试不重复运行。新桌面实际添加、透明效果和Launcher缩放仍待手机反馈；图为实际XML布局的浏览器预览、合成数据，非手机实拍。
